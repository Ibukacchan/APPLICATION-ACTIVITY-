THE ARENA OF EQUALITY — GITHUB PAGES PACKAGE

FILES
- index.html: complete classroom app
- manifest.json: installable PWA metadata
- sw.js: offline cache
- icon-192.png and icon-512.png: app icons

PUBLISH ON GITHUB (ANDROID-FRIENDLY)
1. Create or open a GitHub repository.
2. Upload ALL files in this ZIP directly to the repository root. Do not put them in a folder.
3. In Settings > Pages, publish from the main branch and /(root), or use your existing Pages workflow.
4. Open the published HTTPS site in Chrome.
5. Use Chrome menu > Add to Home screen / Install app.

HOW TO USE
- Students choose their district and read the mission and member list.
- Teacher opens Countdown and starts the 10-minute timer.
- Teacher uses Gamemaker's Control to enter each district's five rubric scores (1–4).
- Scores are saved in the current browser on that device.
- Export results CSV to download a score sheet.

IMPORTANT
- This package uses local browser storage. Scores are not synchronized between phones.
- Use one teacher device for scoring if you want one consolidated score record.
- The app does not transmit student names or scores to a server.
- QR access: create a QR code from your final GitHub Pages URL after publishing.
